# Мини-графический редактор

## 1. Описание задачи

Программа моделирует простую систему графического редактора. Она создаёт круги и квадраты, хранит их координаты на плоскости, вычисляет площадь каждой фигуры и считает общую площадь всех фигур в списке.

Цель работы — применить три основных принципа объектно-ориентированного программирования: инкапсуляцию, наследование и полиморфизм.

## 2. Архитектура проекта

### Инкапсуляция

Базовый класс `Figure` хранит координаты фигуры в атрибуте `_coords`.

Координаты не используются напрямую в основной программе. Для работы с ними созданы публичные методы:

- `get_coords()` — возвращает координаты фигуры
- `set_coords(coords)` — изменяет координаты фигуры

### Наследование

Классы `Circle` и `Square` наследуются от базового класса `Figure`.

```text
Figure
├── Circle
└── Square
```

Класс `Figure` содержит общую логику хранения координат. Дочерние классы добавляют свои характеристики:

- `Circle` содержит радиус `radius`
- `Square` содержит длину стороны `side`

### Полиморфизм

В базовом классе определён общий метод `calculate_area()`. В классах `Circle` и `Square` этот метод реализован по-разному:

- для круга площадь вычисляется по формуле `π × r²`
- для квадрата площадь вычисляется по формуле `a²`

В основной программе все фигуры находятся в одном списке. Один цикл вызывает `calculate_area()` для каждого объекта, не проверяя его тип через `if` или `else`.

## 3. Пример использования

```python
figures = [
    Circle((0, 0), 3),
    Square((2, 4), 5)
]

total_area = 0

for figure in figures:
    total_area += figure.calculate_area()

print(f"Общая площадь: {total_area:.2f}")
```
